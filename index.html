Environment Setup

Installing OpenCV: MacBook vs. Windows

MacBook (Terminal) macOS
  • 1. Open Terminal (Cmd + Space)
  • 2. Run the install command:
$ pip3 install opencv-python
# Verify setup:
$ python3 -c "import cv2"
Use pip3 on Mac so OpenCV installs directly into Python 3.
Windows (Command Prompt) cmd.exe
  • 1. Find Python IDLE folder ➔ Copy its path (or Scripts folder)
  • 2. Open Command Prompt, run cd <path> & install:
C:\> cd C:\Users\Name\...\Python312\Scripts
C:\...\Scripts> pip install opencv-python
Tip: Type cmd in the File Explorer address bar to open right inside that path!
If "pip" is not installed / recognized:
1. Try python -m pip install opencv-python 2. Or run python -m ensurepip --upgrade
Foundation Step 1

Reading & Showing an Image File

STEP 1: STORE Save in Same Folder Put image beside your .py file.
STEP 2: READ Load via cv2.imread() Store image in variable img.
STEP 3: SHOW Display via cv2.imshow() Pass window title + variable.
import cv2
# Step 2: Read image from the same folder into a variable
img = cv2.imread("cat.jpg")
# Step 3: Show image in a popup window (Window Name, Variable)
cv2.imshow("My First OpenCV Window", img)
# Keep window open until a key is pressed
cv2.waitKey(0)
cv2.destroyAllWindows()

Foundation Step 2

Writing & Saving Images + Finding Folder Paths

WRITE & SAVE IMAGE CODE cv2.imwrite(filename, img)
import cv2
# 1. Read original image (using full path or same folder)
img = cv2.imread(r"C:\Users\Student\Pictures\cat.jpg")
# 2. Write & save a new image file into your folder
cv2.imwrite("saved_cat_copy.png", img)
print("Image saved successfully!")
How to Find an Image's Full Path:
Windows: Right-click image ➔ "Copy as path" (or Shift + Right-Click). Add r before quotes!
MacBook: Right-click image ➔ Hold Option (⌥) key ➔ Click "Copy ... as Pathname".
